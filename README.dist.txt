gowithme.club sys plugin для Nintendo Switch (CFW) — версия @VERSION@
=====================================================================

Установка
---------
  1. Скопируй папки atmosphere и config в корень SD-карты.
  2. Открой оверлей (Ultrahand или Tesla) -> Sysmodules -> gowithme.club @VERSION@
     должен быть включён.

Что дальше
----------
  При первом запуске плагин постепенно выгружает историю запусков
  из журнала консоли, пока консоль включена.

Если не заработало
------------------
  Лог плагина лежит на карте: config/gowithme.club/log.txt. Если по нему
  непонятно, что не так, — напиши в поддержку и приложи его.
